# GregTech: Overhead

**GregTech: Overhead** is an addon for GregTech that introduces realistic overhead power transmission lines, high-voltage connectors, and long-distance electrical networks based on *GregTech's Energy Units* (EU).

## Features
- **Overhead Power Lines:** Connect your base, power stations, and outposts across long distances without spamming chunk-loaders.
- **Tiered Connectors:** Voltage tier progression (LV, MV, HV, EV, IV) with authentic ceramic, glass, and composite insulators.
- **Graph-Based Grid:** Power routing handled globally via `SavedData`, energy flows seamlessly through unloaded chunks.
- **Realism & Hazards:** Voltage drops over distance, and real-world high-voltage mechanics.

## Important Notice
> An AI agent is used as a core tool for writing and debugging the mod's codebase. All 3D models and textures are original and handmade.

> I made this mod because I really missed having cables like these in [TerraFirmaGreg-Modern](https://www.curseforge.com/minecraft/modpacks/terrafirmagreg-modern), so yeah...
